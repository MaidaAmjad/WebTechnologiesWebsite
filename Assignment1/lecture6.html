Lecture 6: Common CSS Properties

Exploring the essential styling properties used in CSS

Introduction

CSS (Cascading Style Sheets) controls the look and layout of web pages. It allows you to style HTML elements by changing their colors, fonts, spacing, and positioning. Below are some of the most common CSS properties used by web developers.

1. Background Color

The background-color property sets the background color of an element. 

.box {
  background-color: #4299e1;
}
Blue Box

2. Font Properties

The font-family, font-size, and color properties control the text appearance. 

.box {
  font-family: "Courier New";
  font-size: 18px;
  color: white;
}
Monospace

3. Border

The border property adds borders around elements. You can customize its width, style, and color. 

.box {
  border: 4px dashed #2d3748;
}
Dashed

4. Margin

The margin property controls the space outside an element’s border. 

.box {
  margin-left: 30px;
}
Margin

5. Padding

The padding property adds space inside an element’s border. 

.box {
  padding: 20px;
}
Padding

6. Border Radius

The border-radius property rounds the corners of an element’s border. 

.box {
  border-radius: 20px;
}
Rounded

Conclusion

CSS gives complete control over how a webpage looks and feels. By understanding properties like background, font, border, margin, and padding, you can design attractive and well-structured layouts.
