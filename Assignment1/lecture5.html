Lecture 5: HTML Forms

Understanding Inputs, Select Options, Validation, and Placeholders

Introduction

Forms are an essential part of every website — they allow users to interact, submit data, register, or log in. In HTML, forms are created using the <form> element, which contains various input controls such as text fields, checkboxes, buttons, and drop-down menus.

1. The <form> Element

The <form> element acts as a container for input fields. It can include <input>, <textarea>, <select>, and <button>.

Example: 
<form action="submit.html" method="post">
  <input type="text" name="username" placeholder="Enter your name">
</form>

2. Input Types and Attributes

HTML5 provides various types of <input> elements such as text, email, password, date, and more. Some useful attributes are:

  • placeholder: Displays hint text inside the input field.
  • value: Sets a default value for the input field.
  • required: Makes the field mandatory for submission.
  • type: Defines the kind of input (text, email, password, etc.).

3. Select and Option Elements

The <select> element is used to create a drop-down list, and each option inside it is defined with the <option> tag.

4. Validation in Forms

HTML5 has built-in validation attributes to ensure users enter correct information before submission:

  • required – Field must be filled in.
  • pattern – Defines a custom input format using regular expressions.
  • type – Automatically validates based on input type (e.g., email, number).
Example: 
<input type="email" required placeholder="Enter valid email">
<input type="text" pattern="[A-Za-z]{3,}" placeholder="Only letters allowed">

Conclusion

HTML forms are the foundation of user interaction on websites. With attributes like placeholder, value, and required, we can make our forms both user-friendly and efficient.
