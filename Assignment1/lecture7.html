Lecture 7: CSS Selectors

Understanding how to target elements effectively using CSS

1. What Are Selectors?

CSS selectors define which HTML elements you want to style. They allow you to apply styles precisely, without affecting unrelated parts of your page.

2. Basic Selectors

element — targets HTML tags, e.g. p or h1

.class — targets elements with a specific class

#id — targets a unique element with a specific ID

Example:

p { color: blue; }
.intro { font-size: 18px; }
#mainTitle { text-align: center; }

3. Combinator Selectors

Used to define relationships between elements:

div p — all <p> inside a <div>

div > p — direct child <p> of <div>

div + p — the <p> immediately after a <div>

div ~ p — all <p> siblings of <div>

4. Pseudo-classes

These target elements based on state or position.

a:hover — when a link is hovered

input:focus — when input field is active

li:first-child — first item in a list

li:last-child — last item in a list

5. Pseudo-elements

These let you style specific parts of an element:

p::first-line — first line of a paragraph

p::first-letter — first letter of a paragraph

div::before and div::after — add content before or after elements

6. Attribute Selectors

Target elements based on their attributes or attribute values:

input[type="text"] — targets text input fields

a[target="_blank"] — targets links opening in new tab

[title] — targets any element that has a title attribute

Conclusion

CSS selectors are the foundation of styling — they decide what gets styled. A good understanding of them allows for clean, flexible, and efficient designs.
