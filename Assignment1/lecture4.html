Lecture 4: Key Features of HTML5

Exploring Modern HTML5 Elements and Their Uses

HTML5 introduced a collection of new elements and features that make web development easier, more semantic, and more visually appealing. In this lecture, we’ll explore some of its key features: nav, figure, figcaption, and canvas.

<nav>

The <nav> element defines a section that holds navigation links. It helps users move through your website easily and improves accessibility.

<figure>

The <figure> element groups media content such as images, diagrams, or code snippets along with their caption.

<figcaption>

Placed inside a <figure>, the <figcaption> provides a caption or explanation for the visual content.

<canvas>

The <canvas> element allows drawing graphics, animations, or charts dynamically using JavaScript — though here we’ll just display it visually.
