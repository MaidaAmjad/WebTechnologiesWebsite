Lecture 2: Introduction to HTML

Brief Overview of HTML

HTML (HyperText Markup Language) is the standard language for creating and structuring web pages. It defines the layout and content of a web page using a set of elements represented by tags. Every web page you visit — from social media to online stores — uses HTML as its foundation.

History of HTML

HTML was invented by Tim Berners-Lee in 1991 while working at CERN. Since then, it has evolved through many versions — from HTML 2.0 to the modern HTML5.

Version Year Key Features
HTML 2.0 1995 Basic text, forms, and links
HTML 4.0 1997 Tables, frames, and scripting support
HTML5 2014 Audio, video, semantic elements, and canvas

Difference between HTML & XHTML

XHTML (Extensible HyperText Markup Language) is a stricter and more XML-based version of HTML. It enforces proper nesting and closing of tags, ensuring cleaner and more consistent code.

Example:
✅ XHTML requires lowercase tags and attributes.
❌ HTML allows uppercase or mixed case tags.

Elements and Tags

HTML is made up of elements, each defined by tags. Elements tell the browser how to display content.

Tag Purpose Example
<h1>...</h1> Main heading <h1>Welcome</h1>
<p>...</p> Paragraph <p>This is a paragraph</p>
<a>...</a> Hyperlink <a href="index.html">Home</a>

Block Level vs. Inline Elements

In HTML, elements are divided into block-level and inline categories:

Block-Level Elements Inline Elements
<div>, <h1>, <p>, <ul>, <table> <span>, <a>, <img>, <strong>, <em>
Block-level elements start on a new line and take full width.
Inline elements stay in line with text and take only the required width.

Introduction to HTML Validator

An HTML Validator checks your webpage for syntax errors and ensures it follows web standards. The most commonly used validator is provided by the W3C (World Wide Web Consortium).

✅ Using a validator helps ensure cross-browser compatibility and accessibility.

Conclusion

HTML forms the foundation of every website. Understanding its structure, syntax, and validation ensures cleaner, more professional, and accessible web pages — a crucial step before diving into CSS and JavaScript.
