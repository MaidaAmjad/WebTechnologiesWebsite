Lecture 8: Block, Inline, and Inline-Block Elements

Understanding how elements behave in the page layout

1. Introduction

In HTML, every element has a default display behavior that defines how it appears and interacts with other elements. The three most common display types are block, inline, and inline-block.

2. Block Elements

Block-level elements start on a new line and take up the full width available. Common examples include <div>, <p>, <h1>–<h6>, and <section>.

Example:

<div>This is a block element</div>

3. Inline Elements

Inline elements do not start on a new line and only take up as much width as necessary. Common examples include <span>, <a>, <em>, and <strong>.

Example:

<span>This is inline</span>

4. Inline-Block Elements

Inline-block elements are like inline elements but allow you to set width and height. They appear next to each other while behaving like blocks.

Example:

<div style="display:inline-block">Inline-Block Box</div>

5. Comparison Table

Feature Block Inline Inline-Block
Starts on new line? Yes No No
Can set width/height? Yes No Yes
Default width 100% As content As content (can be changed)
Common examples div, p, section span, a, strong img, button

7. Conclusion

Understanding display types is essential for layout design. block elements structure your page, inline elements style text and links, and inline-block elements give flexibility for grid-like layouts.
