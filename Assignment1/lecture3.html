Table, Div, Span & Layout Design in HTML

This lecture explores how HTML structures web content using elements like table, div, span, and layout containers to organize and style web pages effectively.

1. HTML Tables

Tables arrange data in rows and columns, making information more organized and easy to compare.

Attribute Description Example
border Defines the border thickness around the table. <table border="2">
cellpadding Controls space between cell content and border. <table cellpadding="10">
cellspacing Sets space between cells in the table. <table cellspacing="5">
<table border="1" cellpadding="5" cellspacing="5">
  <tr><th>Name</th><th>Age</th></tr>
  <tr><td>Ali</td><td>21</td></tr>
</table>

Tip: Tables should only be used for data, not for full-page layouts.

2. The <div> Element

The <div> tag represents a block-level container. It’s mainly used for grouping elements, structuring layouts, or applying CSS styling.

<div style="background-color: lightblue; padding: 10px;">
  This is a block container using DIV.
</div>

3. The <span> Element

The <span> tag is an inline container that doesn’t start a new line. It’s ideal for styling or targeting small portions of text.

<p>This is a <span style="color:red;">highlighted</span> word.</p>

Note: Use div for structure and span for styling inline content.

4. HTML Layout Design

Layout design organizes the main areas of a webpage — such as header, sidebar, main content, and footer — for better readability and design balance.
